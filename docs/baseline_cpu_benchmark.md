# 첫 모델 및 CPU 실행 시간 측정

날짜: 2026-10-29

## 모델 구성
ImageNet 사전학습 DenseNet-121을 사용한다. 특징 추출 부분은 고정하고 마지막 층을 폐렴 라벨 유무용 출력 1개로 교체한다. 학습 가능한 파라미터는 1,025개이며 전체 파라미터는 6,954,881개다. 이것은 임상 진단 모델의 검증 결과가 아니라 첫 연구용 기준 모델의 구성이다.

학습에서는 마지막 층만 Adam(lr=0.001)으로 업데이트하고 BCEWithLogitsLoss를 사용한다. 현재 학습 목록은 양성 비율 25%로 재표집되어 있으므로 추가 가중치는 이번 속도 측정에 넣지 않았다. 출력 수치를 임상 유병률에 맞는 확률로 해석하면 안 된다. 최종 분류 임계값은 아직 정하지 않았다.

## 실제 측정
학습용 영상만 32장 선정해 8장씩 처리했다. 첫 묶음은 준비 운동용으로 제외하고 뒤의 3묶음 중앙값을 사용했다. 추론 시간도 동일한 학습용 묶음으로 측정했다. 검증·테스트의 실제 추론이나 성능 평가는 하지 않았다.

환경: CPU, PyTorch 스레드 4개, 이미지 묶음 8장, 데이터 로더 작업자 0개, 입력 224 x 224 RGB.

| 측정 항목 | 시간 |
|---|---:|
| 8장 학습 연산 중앙값 | 0.589초 |
| 8장 파일 읽기·전처리 중앙값 | 0.196초 |
| 8장 추론 연산 중앙값 | 0.358초 |

## 전체 목록으로 단순 환산한 예상치
| 작업 | 예상 시간 |
|---|---:|
| 학습 4,076장 1회 순회 | 약 6.7분 |
| 검증 16,872장 전체 추론 | 약 19.5분 |
| 테스트 16,725장 전체 추론 | 약 19.3분 |

한 번의 학습 순회와 전체 검증을 합하면 약 26분이다. 이는 소표본에 근거한 계산이며 발열, 다른 프로그램, 캐시와 디스크 상태에 따라 달라질 수 있다. 실제 전체 실행 시간이나 성능 측정값은 아니다.

## 확인 완료
- 모델 출력과 정답의 모양이 일치하고 손실과 출력이 유한한 값임을 확인했다.
- 특징 추출 부분의 학습 가능 설정이 꺼져 있고, 확인한 특징 추출 가중치와 BatchNorm 평균값이 변하지 않았다.
- 마지막 분류층의 가중치는 실제로 업데이트되었다.
- 속도 측정에 사용한 임시 모델은 저장하지 않았다. 본 학습은 새로 초기화해 시작해야 한다.
- 사전학습 가중치는 프로젝트의 `outputs/models/torch_cache/`에 저장된다. Git에서 제외되는 위치다.

구현: `src/model.py`, `scripts/benchmark_cpu.py`
측정 결과: `outputs/metrics/cpu_benchmark.json`

## 다음 선택
특징 추출기를 고정하는 동안에는 이미지별 특징을 한 번 계산해서 저장하고 마지막 분류층 학습에 재사용할 수 있다. 같은 특징 추출 연산을 매 학습·검증마다 반복하지 않아 CPU 실행 시간을 줄일 수 있다. 데이터 증강이나 특징 추출기 미세조정을 시작하면 이 저장 특징 재사용 방식은 그대로 적용할 수 없다. 아직 특징 저장이나 본 학습은 수행하지 않았다.
