## 강의 자료와 일치하는 부분
NIH ChestX-ray14 사용, Pneumonia 라벨 포함 여부를 0/1로 생성, 환자 단위 누수 방지, 224x224와 3채널 입력, 사전학습 가중치 활용, AUROC뿐 아니라 AUPRC를 보는 방향은 연결되어 있다. 강의 3의 모델 비교표에도 DenseNet-121이 등장한다. 따라서 DenseNet 선정 자체가 강의와 무관하게 다른 프로젝트로 바뀐 것은 아니다.

## 달라진 부분
1. 분할: 우리 쪽은 환자 표를 먼저 만들고 폐렴 라벨 영상 보유 여부를 층화해 70/15/15로 나눴다. 강의 1은 GroupShuffleSplit을 사용한다. 강의 설명은 8:1:1이지만 실제 예시는 첫 단계 test_size=0.20, 남은 부분에서 val_size=0.125라 환자 기준 약 70/10/20이 된다. 이 차이는 자료 내부 불일치이므로 현재 분할을 즉시 바꾸지 말고 재현 기준을 명시한다.
2. 학습 표본: CPU용으로 양성 1,019장과 음성 3,057장을 사용하도록 바꿨다. 강의 4의 중심 실습은 원래 불균형을 대상으로 양성 손실 가중치(pos_weight)를 사용한다. 음성을 줄이는 방법과 손실 가중치는 다른 전략이다. 현재 학습 비율에 원래 1.3%용 가중치를 그대로 적용하면 안 된다. 아직 본 학습은 없으므로 전략을 다시 선택할 여지가 있다.
3. 전처리: 강의 2는 학습·평가 모두 CLAHE를 적용하고, 학습에는 회전·밝기·crop 등 무작위 증강을 넣는다. 현재 코드는 CLAHE와 증강 없이 같은 변환을 모든 그룹에 적용한다. 이는 단순한 기준 모델을 먼저 보려던 별도 선택이며 강의의 증강 학습을 완료한 것이 아니다.
4. 구현 도구: 강의 2는 Albumentations와 사전형 데이터 반환, 현재는 torchvision과 (영상, 정답) 쌍 반환이다. 기능적으로 가능한 방식이나 초보 학습자가 코드를 대조하기에는 차이가 난다. 라이브러리 전체를 급히 바꾸기보다 강의 코드와 대응표를 작성한다.
5. 학습 방식: 현재 DenseNet은 특징 추출 부분을 고정하고 분류층만 학습하도록 준비했다. 강의 4는 ViT에 대해 분류층만 학습, 전체 미세조정, 층별 학습률 등을 설명하며 중심 실습은 ViT LLRD이다. 현재 방식은 강의에서 소개한 전략 중 단순한 쪽에 해당하며 ViT 중심 실습의 대체 완료가 아니다.
6. 특징 저장: CPU 속도 개선 방법으로 제안만 했고 구현하지 않았다. 고정된 특징을 재사용하면 매번 무작위로 영상을 바꾸는 강의 증강 방식을 그대로 적용할 수 없다. 증강 계획을 먼저 정한 뒤 채택 여부를 정한다.
7. 추가한 검수: 원본 파일 해시뿐 아니라 픽셀 해시로 중복을 찾았고 6장 제외 내역을 남겼다. 이는 강의 흐름을 대체하는 것이 아니라 데이터 검수를 보강한 작업이다.
8. DICOM 변환: 이번 자료는 이미 PNG이므로 DICOM windowing과 MONOCHROME1 처리를 실행하지 않았다. 해당 개념은 강의에서 이해할 내용이며 이 PNG 데이터의 필수 실행 단계가 빠진 것은 아니다.

## 자료를 읽을 때 주의할 점
- 강의 2의 정규화 후 mean≈0/std≈1은 ImageNet 통계가 다른 도메인에 적용될 때 정확히 보장되지 않는다. 통계는 기록하되 숫자가 정확히 0/1이 아니라고 실패로 처리하지 않는다.
- 강의 4 코드의 예시 그림에 음성을 '정상'으로 표시한 부분은 이번 프로젝트에서는 '폐렴 라벨 없음'으로 표현한다.
- 강의 4의 출력 1개 설정은 실제 손실 함수와 맞춰야 한다. 현재 DenseNet 속도 측정은 float 정답과 BCEWithLogitsLoss를 실제 실행해 확인했다.
- 강의 5·6의 평가, 환자 단위 신뢰구간, 임계값, 하위그룹, Grad-CAM·Attention 검증은 미래 단계다. 아직 수행하지 않았다. 코드·설명의 세부 정확성은 실제 구현 때 재검증한다.

## 권장 재개 순서
1. 01_EDA.ipynb로 기존 결과를 설명과 함께 정리: PA/AP 양성률, 환자 분할 이유, 영상 단위 분할의 누수 비교 포함.
2. 학습 샘플로 원본/Resize/CLAHE 전후를 나란히 비교. CLAHE를 쓴다면 평가에도 같은 결정적 처리를 적용.
3. 강의와 연결해 약한 회전·밝기 증강을 구현하고 동일 영상의 반복 결과를 시각화. 좌우·상하 반전은 이 강의 흐름에서 사용하지 않음. Crop 등 추가 증강은 영상 손실을 보며 선택.
4. 학습용·평가용 변환 분리, 실제 처리 배치 시각화, 평가 결정성·통계 확인.
5. README와 검수 기록 정리 후 Day 2 변경 커밋·푸시.
6. 위 항목을 완료한 뒤 2주차로 이동: 학습 표본·불균형 처리·학습 범위(분류층만/미세조정)를 설명하고 정한 후 첫 본 학습.
