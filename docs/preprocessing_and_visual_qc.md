# 전처리 및 학습 영상 샘플 검토

작성일: 2026-10-29

## 검토 범위
최종 QC 학습 목록에서 폐렴 라벨 영상 6장, L 형식 음성 영상 4장, RGBA 영상 2장을 고정 난수 42로 선정했다. 총 12장이며 전체 데이터의 화질이나 라벨 정확성을 대표하는 검사는 아니다. 검증·테스트 영상은 이번 샘플 검토에 사용하지 않았다.

## 육안으로 확인한 사항
- 샘플에 촬영 범위, 밝기, 대비와 테두리의 차이가 있다.
- 문자, 방향 표시, PORTABLE/AP 등의 표시와 선·기기가 보이는 샘플이 있다. 모델이 이런 요소를 단서로 이용할 가능성은 이후 오류 분석에서 확인해야 하며, 현재 확인된 사실은 표시와 기기가 보인다는 것이다.
- 이번 샘플에서 빈 화면이나 파일 표시 실패는 발견하지 못했다.
- 임상 진단이나 원본 라벨의 정확성을 판정한 것은 아니다. 샘플 검토로 새롭게 제외하거나 라벨을 변경한 영상은 없다.

## 첫 모델의 전처리 기준
1. RGB 3채널: 입력 형식을 통일한다. 흑백 L 영상은 동일한 밝기 값을 3채널로 복제한다. 원본 파일은 변경하지 않는다.
2. 224 x 224: 모든 원본이 정사각형이므로 비율을 유지해 전체 영상을 축소한다. 중앙 잘라내기는 적용하지 않는다. 작은 영상 세부 정보가 줄어드는 한계가 있다.
3. 텐서 변환 및 ImageNet 정규화: ImageNet 사전학습 CNN을 사용할 계획에 맞춘 초기 기준이다. 향후 다른 사전학습 가중치를 선택하면 해당 입력 조건을 다시 확인한다.
4. 첫 기준 모델에는 회전, 뒤집기, 밝기 변경 같은 데이터 증강을 적용하지 않는다. 학습·검증·테스트에 같은 결정적 전처리를 적용한다.

## 구현과 확인 결과
- `src/preprocessing.py`: 위 변환을 만드는 `build_transform`.
- `src/dataset.py`: QC 목록에 있는 영상만 읽는 `ChestXrayDataset`.
- `scripts/preview_preprocessing.py`: 샘플 선정, 그림 저장 및 실제 데이터 로더 확인.
- 학습 목록 4,076장 로딩 가능. 첫 묶음 8장의 입력 모양은 `(8, 3, 224, 224)`, 정답 모양은 `(8,)`.
- 선정된 12장의 전처리 결과 모양과 유한한 수치 여부 확인. L/RGBA와 양성/음성 입력을 포함한다. 전체 영상 전처리 완료나 모델 학습 완료를 의미하지 않는다.
- 전체 원본의 읽기 검사는 이전 이미지 QC 단계에서 완료했다. 유사 이미지 중복 검사는 아직 미완료다.
