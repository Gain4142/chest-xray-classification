# B0 기본 모델 학습

실행: 프로젝트 루트에서 `.\.venv\Scripts\python.exe -m src.train`

기본 조건은 3에포크, batch 8, Adam 학습률 0.001, seed 42, CPU 4스레드다.
ImageNet DenseNet-121의 특징 추출부와 BatchNorm 통계를 고정하고 분류층만 학습한다.
증강, CLAHE, 추가 클래스 손실 가중치는 적용하지 않는다.
학습 순서는 매 에포크 섞고 검증은 고정 순서로 전체 목록을 사용한다.

검증 AUROC가 가장 높은 에포크를 best.pt에 저장한다. 동점이면 먼저 나온 에포크를 유지한다.
매 에포크의 학습·검증 손실, AUROC, AUPRC 및 소요 시간을 history.csv에 기록한다.
AUPRC는 sklearn average precision 정의를 사용한다. 학습 지표는 에포크 도중 갱신되는 모델의 집계다.
테스트 데이터는 이 명령에서 읽지 않는다. 임계값과 최종 테스트 평가는 후속 단계다.

결과는 outputs/models/<run-name>/에 저장되며 Git에서 제외된다.
config.json에는 설정과 사용한 목록의 SHA-256을, last.pt에는 모델·최적화 상태 및 난수 상태를 저장한다.
기존 실행 폴더를 덮어쓰지 않는다. 재실행은 --run-name으로 새 이름을 지정한다.
자동 재개는 아직 지원하지 않는다. 중단 시 마지막 완료 에포크의 체크포인트가 남는다.

실행 점검은 `--smoke --epochs 1 --run-name B0_smoke_20261030`으로 수행한다.
이때 학습 영상 32장만 사용하며 같은 영상으로 저장·복원 경로를 확인한다.
따라서 점검 모드의 val 지표는 실제 검증 성능이 아니다.
특징 추출부 전체 상태·BatchNorm 통계 고정, 분류층 갱신, 저장 후 동일 예측 복원을 검사한다.

## 2026-10-30 학습 완료 및 곡선 확인

B0는 3에포크를 완료했으며 학습·검증 합계는 89.7분이다. 검증 AUROC 기준 best.pt는 3에포크다.

| 에포크 | 학습 손실 | 검증 손실 | 검증 AUROC | 검증 AP |
|---|---:|---:|---:|---:|
| 1 | 0.5443 | 0.4106 | 0.6828 | 0.02351 |
| 2 | 0.5316 | 0.2223 | 0.6842 | 0.02345 |
| 3 | 0.5223 | 0.1875 | 0.6849 | 0.02372 |

검증 손실은 감소했지만 순위 구분 지표인 AUROC와 AP의 개선은 작다. 세 에포크만으로 수렴이나 과적합 여부를 단정할 수 없다. 검증 양성률은 218/16,872 = 1.292%이며 AP 2.372%는 무작위 순위의 기대 기준인 양성률의 약 1.84배다. 이것이 임계값별 정밀도나 임상 유용성을 뜻하지는 않는다.

학습 양성률은 25%로 검증과 다르고, 학습 지표는 파라미터 갱신 중 집계한다. 따라서 학습·검증 손실과 AP의 크기를 그대로 비교해 과적합을 판단하지 않는다. 테스트는 실행하지 않았다.
