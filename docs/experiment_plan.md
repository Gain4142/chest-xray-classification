# 기본 모델 및 후속 비교 실험 계획

## 현재 상태
기본 모델의 본 학습은 시작하지 않았다. 학습 영상 32장을 사용한 속도 측정만 수행했으며 임시 모델은 저장하지 않았다. 이 문서는 첫 실험과 후속 비교의 범위를 명시한다.

## 공통 조건
- 데이터: `data/processed/reduced_train_full_eval_qc/`의 고정 목록. 학습 4,076장, 검증 16,872장, 테스트 16,725장.
- 타깃: Pneumonia 라벨 포함 여부. 음성은 정상 확진을 의미하지 않는다.
- 모델: ImageNet-1K 사전학습 DenseNet-121, 특징 추출부 및 BatchNorm 통계 고정, 마지막 1-logit 분류층만 학습.
- 기본 입력: RGB 3채널, 224 x 224 bilinear 축소, ImageNet 정규화.
- 불균형: 학습 목록에서 양성:음성 1:3. 기본 실험에는 원본 양성률에 근거한 추가 손실 가중치를 적용하지 않는다.
- 비교 시 고정할 항목: 환자 분할, 학습 목록, 사전학습 가중치, 초기화 난수, 데이터 순서, 손실, 최적화 설정, 학습 횟수 및 검증 지표.

학습률, 에폭 수와 저장·재개 정책은 학습 진입점을 구현하면서 설정 파일에 확정한다. 현재 속도 측정에 사용한 batch=8, Adam lr=0.001은 실행 가능한 초기 후보이며 최적 조건으로 검증한 값이 아니다.

## 실험 구분
| ID | 학습 증강 | CLAHE | 의미 |
|---|---|---|---|
| B0 | 없음 | 없음 | 기본 모델 |
| A1 | 약한 회전·밝기·대비 | 없음 | 증강만 변경 |
| C1 | 없음 | 동일 조건으로 학습·평가 모두 적용 | CLAHE만 변경 |

A1의 후보 설정은 ±5도 회전(확률 0.5), 밝기·대비 계수 0.9~1.1(조정 묶음 확률 0.5)이다. C1의 후보는 clipLimit=2.0, tileGridSize=(8,8)이며 원본 해상도에서 적용한다. 모두 시각 검토를 수행한 초기 후보이고 성능 개선을 확인한 조건은 아니다. 두 처리를 동시에 넣는 실험은 이 세 가지 비교 이후 별도로 판단한다.

## 선택과 평가
검증 AUROC·AUPRC와 손실 곡선을 기록하고 검증 결과에 따라 체크포인트와 방법을 선택한다. 임계값 역시 검증에서 정하며 테스트 결과로 방법이나 조건을 고르지 않는다. 최종 선택을 확정한 뒤 테스트 평가를 수행한다. 여러 모델을 최종 보고서에서 비교할 경우 비교 대상과 평가 조건을 테스트 실행 전에 고정한다.

환자 단위 신뢰구간, AP/PA 등 하위그룹과 실패 사례 분석은 성능 보고의 후속 항목이다. 외부 검증 없이 실제 진료 환경의 성능을 주장하지 않는다.

## 구현상 주의
무작위 증강은 학습 입력을 읽을 때 수행한다. 시각화에서 사용한 것처럼 매 영상마다 같은 시드를 다시 설정하지 않는다. 데이터 순서용 난수와 증강용 난수가 서로 영향을 주지 않게 관리한다. 검증·테스트는 결정적인 전처리만 사용한다.

고정 특징 저장은 아직 구현하지 않았다. 저장한 특징만 재사용하면 매 순회마다 달라지는 영상 증강을 반영할 수 없으므로 B0와 A1을 공정하게 비교하는 입력 경로를 먼저 정한다.
