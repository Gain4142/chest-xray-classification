# Colab GPU에서 ViT CLAHE 실험 실행

1. https://colab.research.google.com 에서 ViT_CLAHE_Colab.ipynb를 업로드해 연다.
2. 런타임 → 런타임 유형 변경에서 GPU를 선택한다.
3. Google Drive의 MyDrive/CXR_CLAHE/에 vit_clahe_colab.zip(약 8.43 GB)을 업로드한다. 기존 Drive 파일과 합쳐 충분한 여유 공간이 필요하다.
4. 노트북 셀을 위에서부터 실행하고 Drive 연결을 허용한다.
5. GPU 소량 점검, 같은 GPU에서 기본 ViT와 CLAHE ViT 학습, 최적 모델별 검증 예측과 비교표 생성 순서로 진행된다.
6. Drive의 CXR_CLAHE/results/clahe_comparison.csv와 두 history.csv를 로컬로 가져온다. 모델 체크포인트도 각 실행 폴더에 남는다.

학습 조건은 3에포크, batch 8, seed 42, Adam 0.001, BCEWithLogitsLoss, 분류층만 학습이다. CLAHE 조건은 원본 이미지에 clip limit 2.0, tile grid 8×8을 적용한다. 비교의 주 기준은 같은 GPU에서 실행한 두 조건의 검증 결과다. 기존 CPU 결과도 ZIP 안 reference_vit에 포함했다.

데이터는 원본 PNG 중 기존 학습·검증 목록 20,948장만 포함한다. ZIP은 Colab 로컬 디스크에 풀고 결과는 Drive에 저장한다. 노트북에는 최신 소스가 들어 있으며 압축 해제 후 이를 적용한다. 모델 가중치는 고정한 Hugging Face revision에서 최초 다운로드한다.

로컬에서 CLAHE 켠 32장 학습 및 모델 저장·복원 점검을 통과했다. 노트북 형식과 실행 셀 구문, ZIP 목록과 분할 일치를 검사했다. 이 컴퓨터에서 CUDA 실행과 실제 Colab 세션은 검증하지 않았다. GPU 할당과 실행 시간은 Colab 환경에 따라 다르며 실제 소요 시간은 GPU에서 실행 후 확인한다.

런타임 종료 시 로컬 압축 해제 파일은 사라질 수 있다. 모델은 매 완료 에포크마다 Drive에 저장한다. 중단된 실행을 자동 재개하는 기능은 현재 없으며 노트북은 기존 미완료 실행 폴더를 발견하면 멈춘다. 재실행하려면 새 run-name을 지정한다. 이미 완료한 실행은 재사용한다.
